# Sistema de Reservas
Aplicación de escritorio para gestionar la reserva de recursos institucionales: funcionarios, categorías, recursos, reservas, calendarización, actividades y estadísticas.
El sistema usa Java (Swing), Maven y persistencia en archivos XML. Incluye inicio de sesión, roles de administrador y funcionario, y generación de reportes.

## Cómo ejecutar
Requisitos: Java 22 y Maven.
```bash
mvn compile
mvn exec:java -Dexec.mainClass="Application"
```
También se puede abrir el proyecto en IntelliJ IDEA y ejecutar la clase `Application`.
